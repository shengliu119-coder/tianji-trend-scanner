# 天机伏击·三模型并行扫描库

这个仓库里的扫描器会每小时自动运行，专门盯币圈的趋势起爆、回踩确认，以及主流币大周期反转机会。

现在的接入方式是：

- **三模型并行**：旧模型 `天机伏击·趋势回踩模型` + 短线起爆模型 `天机伏击·A/B趋势起爆模型` + 主流币大周期反转模型 `天机伏击·主流币大周期反转模型`
- **独立记录**：每个模型各自有状态、台账和绩效统计
- **对外优先级**：同币种只保留更强的一条外显，大周期反转模型优先于短线模型
- **自动化不变**：继续由 GitHub Actions 每小时运行

## 会产出什么

- `state/signals.json`：每个模型自己的去重与生命周期状态
- `state/trades.jsonl`：模型级机会台账
- `state/performance.json`：自动绩效汇总
- `reports/performance.md`：可读版绩效报告
